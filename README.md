# Product Consolidation

Konsolidierung der Produktdaten aus:

- identbase.de – Magento – preisführende Instanz
- identible.de – interaktiv.net
- inplastor.at – interaktiv.net
- cardnext.de – interaktiv.net

## Ziel

Erstellung eines konsolidierten Master-Produktdatenbestands und einer
importfähigen Datei für die neue Cardnext-Plattform.

## Wichtige Regel

Die Produktpreise aus identbase.de sind führend.

Die Originaldateien unter `raw/` dürfen durch Verarbeitungsskripte nicht
verändert werden.
